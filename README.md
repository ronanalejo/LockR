# lockr-ui
UI component library and design system for the LockR thesis project. Provides reusable, consistent, and scalable UI components for the web app.

## 🎯 Purpose
- Provide a consistent look and feel across the LockR platform.  
- Speed up development by reusing pre-styled components.  
- Serve as a playground for frontend team members to design, test, and refine UI elements.  

## 📂 Folder Structure
src/
components/ui/ # Core reusable UI components
styles/ # Global styles and variables
stories/ # (Optional) Storybook component previews

## 🚀 Getting Started
1. Clone this repo:
   git clone https://github.com/<org>/lockr-ui.git
   cd lockr-ui
   
2.Install dependencies:
  npm install

3.Run the dev server:
  npm run dev


✅ Contribution Guidelines
Place all reusable UI components inside src/components/ui/.

Keep components small, composable, and well-documented.

Use Tailwind CSS for styling consistency.

Commit with descriptive messages (e.g., feat: add Button component).
